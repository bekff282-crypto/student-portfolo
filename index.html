06 / ДИЗАЙН ИНТЕРФЕЙСА

Принципы UX/UI

01

Визуальная иерархия

Заголовки крупнее основного текста, поэтому посетитель быстро понимает, где находится важная информация.

02

Контрастность

Светлый текст на тёмном фиолетовом фоне помогает читать содержимое сайта.

03

Единообразие

Карточки, кнопки, отступы и цвета повторяются во всех разделах, создавая единый стиль.

04

Удобная навигация

Меню содержит ссылки на основные разделы, а кнопки помогают быстро перейти к работам.

05

Адаптивность

Сетка карточек и меню перестраиваются на узком экране, чтобы сайтом было удобно пользоваться на смартфоне.

07 / ТЕХНОЛОГИИ

HTML, CSS и JavaScript

Примеры технологий, использованных при создании портфолио.

HTML — структура

header — шапка сайта.

nav — навигация.

main — основное содержимое.

section — тематический раздел.

article — самостоятельная карточка.

h1–h3 — заголовки.

p — абзац.

a — ссылка.

button — кнопка.

img — изображение.

form — форма.

input — поле ввода.

CSS — оформление

color — цвет текста.

background — фон.

font-family — шрифт.

font-size — размер текста.

margin — внешние отступы.

padding — внутренние отступы.

display — способ отображения.

grid — сетка карточек.

border-radius — скругление углов.

box-shadow — тень.

max-width — ограничение ширины.

transition — плавный переход.

JavaScript — интерактивность

Переключение светлой и тёмной темы.

Поиск работ по названию.

Фильтрация карточек по категориям.

Модальное окно с подробностями.

Проверка формы и сообщение об отправке.
