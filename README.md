# Портфолио Бекзата Баймурзинова

Учебное портфолио веб-дизайнера, группа WD-2-135.

## Запуск
Открой `index.html` в браузере.

## Публикация на GitHub Pages
1. Создай репозиторий на GitHub.
2. Загрузи все файлы и папки проекта.
3. Открой Settings → Pages.
4. Выбери Deploy from a branch, ветку `main` и папку `/ (root)`, затем Save.
