# Мои учебные работы

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите `index.html`, `style.css`, `script.js` и `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. Откройте ссылку, которую GitHub покажет в разделе Pages.

Перед сдачей внесите фактические результаты диагностики учебного ПК и собственные результаты теста клавиатуры/мыши. Для задания 05.11 сделайте свои скриншоты VirtualBox и Ubuntu. Сметы сборок ПК ориентировочные, а не текущие цены магазина.
